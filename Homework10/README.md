# Программа на 8 для побитовой передачи целого числа с использованием сигналов SIGUSR1/SIGUSR2 (Дз 10)

## Исполнитель
- **ФИО:** Чекмарев Трофим Владимирович  
- **Группа:** БПИ-245  

## Краткое описание программы
Реализованы две независимые программы: передатчик (`bit_sender.c`) и приёмник (`bit_receiver.c`), которые запускаются в разных терминалах и обмениваются данными только с помощью пользовательских сигналов `SIGUSR1` и `SIGUSR2`.

Каждая программа при старте:
- печатает свой PID;
- запрашивает с клавиатуры PID собеседника, который вводит пользователь.

Передатчик запрашивает с клавиатуры одно целое десятичное число (может быть отрицательным), после чего передаёт его побитово приёмнику как 32-битное значение (`int32_t`) в дополнительном коде:
- бит `0` передаётся сигналом `SIGUSR1`,
- бит `1` передаётся сигналом `SIGUSR2`,
- биты передаются от старшего к младшему.

Для надёжности каждый бит передаётся асинхронно с подтверждением:
- после получения любого бита приёмник тут же отправляет передатчику подтверждение сигналом `SIGUSR1`;
- передатчик ждёт это подтверждение (через `sigsuspend` и маскирование сигналов) и только после этого посылает следующий бит;
- отсутствие подтверждения считается грубой ошибкой и предотвращает дальнейшую отправку.

Завершение передачи реализовано с помощью сигнала `SIGINT`: после отправки всех 32 бит передатчик посылает приёмнику `SIGINT`, а приёмник, получив его, прекращает ожидание битов, восстанавливает число из принятых 32 бит и выводит его в десятичной форме (и в шестнадцатеричном виде для наглядности). После этого обе программы корректно завершают работу.

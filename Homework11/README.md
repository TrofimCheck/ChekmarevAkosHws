# Программа для асинхронного параллельного суммирования с использованием POSIX threads (Дз 11)

## Исполнитель

- **Группа:** БПИ-245  

## Краткое описание программы
Реализована программа async_sum.c, моделирующая асинхронную обработку данных по схеме из задания: есть 100 параллельных источников, общий буфер и множество сумматоров, работающих одновременно.

В программе используются потоки POSIX (pthread):

- 100 потоков-источников порождают числа от 1 до 100 (каждый источник - своё число).  
  Перед помещением числа в буфер поток источника засыпает на случайный промежуток времени от 1 до 7 секунд (sleep), имитируя различную скорость поступления данных.

- Общий буфер реализован как защищённый mutex’ом массив целых чисел.  
  Количество элементов в буфере отслеживается переменной buf_count.  
  Для синхронизации используется pthread_mutex_t и условная переменная pthread_cond_t.

- Поток-монитор непрерывно отслеживает состояние буфера:
  - как только в буфере появляется минимум два числа, монитор забирает пару (две любые, в реализации последние) и запускает поток-сумматор;
  - число активных сумматоров учитывается переменной active_summators.

- Потоки-сумматоры получают два числа, «считают» их сумму в течение случайного времени от 3 до 6 секунд (задержка sleep), после чего помещают результат обратно в общий буфер, откуда он может быть снова взят монитором для дальнейшего суммирования с другими числами или промежуточными результатами.

Выполнение программы завершается, когда:
- все 100 источников завершили работу;
- все сумматоры отработали (нет активных сумматоров);
- в буфере осталось ровно одно число - окончательный результат суммирования всех исходных чисел и промежуточных результатов.
